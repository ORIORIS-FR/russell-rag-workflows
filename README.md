# Workflows n8n — catalogue public

Ce dépôt accueillera progressivement des workflows nettoyés et anonymisés, accompagnés d’une analyse, d’un schéma et d’une installation pas à pas.

**Remise à plat du 21 novembre 2026 : aucun workflow disponible pour le moment.** Les anciens candidats et démonstrations ont été retirés de la version courante. Ils ne constituent plus la base du projet.

Le travail repart des workflows réels dans un catalogue privé. Les versions publiques seront préparées depuis ces références et documenteront explicitement leurs sous-workflows et leurs dépendances. Aucune version de remplacement n’est inventée ici.
