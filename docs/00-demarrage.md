# Commencer avec le kit public

Ce dépôt contient deux candidats n8n, leurs sources, des tests sans services et deux sous-workflows de démonstration. Il est indépendant du dépôt de travail privé ; aucune donnée de production n'est incluse.

1. Cloner le dépôt et exécuter les tests locaux.
2. Lire [l'installation pas à pas](03-installation.md).
3. Utiliser un environnement de test et des notes fictives.
4. Importer les fichiers optimisés sans les activer.
5. Vérifier le plan en simulation avant tout appel modèle ou écriture.

Les [diagrammes](diagrams/index.html) expliquent le candidat, pas une installation déjà faite chez vous. Les [mocks](../workflows/demo/) montrent les contrats des sous-workflows sans accès disque ni shell.
